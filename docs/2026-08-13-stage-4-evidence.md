# Stage 4 BGM 元数据证据报告

> 版本：`0.4.8`
> 日期：2026-08-13
> 状态：功能通过；双向与连续命中导航人工验收通过，绝对零音频/零帧仍未验证

## 范围结论

Stage 4 将 BGM 名称作为现有视频决策控制器的第二个数据源。BGM 同时覆盖原声条目 `music.title/musicName` 和平台明确关联歌曲 `relatedMusicAnchor.extra.title`。视频文本或任一 BGM 名称命中都进入同一条 `processCard -> handleCurrentDecision -> requestNext` 导航链，不存在第二套滚动、点击或熔断逻辑。弹幕过滤仍是独立的页面级显示模块。

实现只观察页面本来会接收的数据：首屏静态读取 `createQuickPlayer(...)` 源码片段，后续只读观察同源 `GET /aweme/v1/web/tab/feed/` 的 XHR/fetch 响应。脚本不调用私有接口，不声明 `GM_xmlhttpRequest` 或 `@connect`，不发送额外请求。

## 已确认的源码行为

- QuickPlayer 解析器只扫描字符串和对象边界，不使用 `eval`、`Function` 或页面回调；
- 响应提取只保留 `awemeId`、`musicTitle`、`musicName`、`relatedMusicTitle` 四个字段；
- `awemeId`、`aweme_id`、`gid` 必须是精确字符串 ID；缺失、数字 ID、部分无效、多 ID 冲突均拒绝关联；
- 缓存上限为 500 个 ID/冲突标记，访问时更新 LRU 次序；同一 ID 元数据不一致时删除值并标为冲突；
- fetch 包装保持原 `this`、参数和 Promise 身份，只异步读取 clone；
- XHR 包装保持 `open`/`send` 的 `this`、参数、返回值和异常，只在 `loadend` 后的微任务读取响应；
- 停止时移除待处理监听器，仅当页面函数仍是本脚本包装时恢复，绝不覆盖后来者；
- 包装安装失败时回滚已安装部分，BGM 数据源 fail-open，不影响视频文本或弹幕功能；
- 当前 epoch 达到 250ms 后形成终局 `bypass`，迟到 BGM 不会在观看中途突袭跳过；
- 当前 `0.4.8` 不写 `muted`，不调用 `pause()` 或 `play()`。

## 首次实页结果与根因

`0.4.0` 在 Chrome + Tampermonkey 中确认：

- 新增 BGM 规则不会突袭当前稳定视频；
- 离开后返回目标视频，状态先为 `pending`，约 250ms 后转为终局 `bypass`，没有错误跳过；
- 用户可见的“汽水音乐: blame the moon”是平台关联歌曲，右侧“创作的原声”是抖音原声音轨条目，两者都应属于 BGM 过滤范围；
- QuickPlayer 中原声位于 `awemeInfo.music`，关联歌曲位于同一个 `awemeInfo.relatedMusicAnchor.extra` JSON 字符串。

未命中的根因是 `0.4.0` 静态解析器没有将字段查找限定在对象顶层，先遇到 `awemeInfo` 内其他嵌套对象的同名 `music` 后 fail-open。`0.4.1` 改为层级感知的顶层属性读取，并加入关联歌曲最小字段。

## 0.4.1 至 0.4.8 实页结论

用户在 Chrome + Tampermonkey 保存 `0.4.1` 并配置真实 BGM 名称后，确认过滤与自动跳过已经生效，但最初观察到明显延迟。现场计时随后确认旧导航会在命中卡激活后等待 2.5 秒确认超时。

`0.4.2` 至 `0.4.8` 的现场诊断进一步确认：抖音虚拟列表在活动卡标识变化后仍保留过渡锁，锁内的脚本点击会被吞掉；向上进入历史命中卡时若固定调用下一条，还会与用户方向反向争用；连续命中时则必须把方向和过渡等待保持到整条链结束。`0.4.8` 改为按真实输入方向使用上一条/下一条控件，每条命中等待其动画容器的 `transitionend/transitioncancel`，事件缺失时以 350ms 兜底，并只在遇到 `allow/bypass` 后结束连续跳过事务。用户以视频标题关键词“你”完成连续命中手工验收并确认恢复正常。

因此 Stage 4 按以下分层收敛：

- 原声名称与平台关联歌曲名称均进入同一 BGM 词表：通过；
- 视频 ID 精确关联、缺失时 fail-open：源码和离线回归通过；
- BGM 命中后使用统一导航链自动跳过：用户手工通过；
- 配置不突袭当前稳定视频、250ms 后迟到数据不突袭：浏览器观察通过；
- 双向及连续命中导航：`0.4.8` 用户手工通过；命中画面在等待过渡期间保持视觉门控；
- 绝对零音频/零帧：未验证，不由本次人工体验验收替代；
- Network 面板无新增请求、页面性能增量：本轮未取得独立人工面板证据，不冒充已通过。

Node 测试不证明 Tampermonkey 注入时序、当前页面真实响应结构、实际 BGM 命中、Network 无新增请求或页面性能。

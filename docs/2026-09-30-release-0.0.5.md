# 0.0.5 发布说明

`0.0.5` 是继 `0.0.4` 之后的正式版本，修复命中卡导航的方向、人工接管、超时和目标确认边界。

## 变化

- 可信上翻进入随后命中的卡片时，即使页面控件可用，也保留向上方向；等待、沉降和重试在派发前复核推荐路由、唯一 Feed 根、当前卡及交互状态。
- 人工输入取消旧等待与沉降任务，再记录新方向；已到期的动画或队列等待不会因迟到就绪继续派发。
- 只有确认到达目标卡才继承方向并计入连续跳过熔断。原生目标取自已验证队列，未知或意外目标停止连续跳过。
- 视频/BGM 原始配置文本变化可解除熔断；无效弹幕 ID 放行。显式诊断探针在派发前再次检查动画状态。
- 移除手工配置的 `@updateURL`、`@downloadURL`，遵循仓库元数据规则；更新使用全文替换流程。

## 验证与限制

源码语法检查、254/254 Node 回归及差异检查通过。默认测试隔离受环境 `spawn EPERM` 限制，全量回归使用 `node --test --test-isolation=none`。

Chrome + Tampermonkey 发布前取得连续两张命中的双向过滤、直播止步、当前卡配置保护、搜索焦点冒烟、等待期人工接管和一次 SPA 清理/恢复证据；用户已恢复原配置。实页安装产物当时仍标记为 `0.0.4`，随后只修改版本元数据，不能将其写成 `0.0.5` 安装后的独立实测，详见[实页验收报告](2026-09-30-real-page-acceptance.md)。

队首和重复往返仍出现 `queue-timeout` 放行。快速反向输入未可靠落入目标等待窗口；语义控件、模态框、后台、实页熔断及精确超时边界尚未闭环。其他浏览器、网络/性能和音频/逐帧目标没有本版新增证据。

## 更新

从 [正式脚本地址](https://raw.githubusercontent.com/Onlydreams/douyin-web-enhancer/master/douyin-web-enhancer.user.js) 获取全文，在 Tampermonkey 中替换、保存并刷新推荐页。版本应显示 `0.0.5`。不要将诊断探针作为产品安装，也不要依赖较高测试版号自动降级。

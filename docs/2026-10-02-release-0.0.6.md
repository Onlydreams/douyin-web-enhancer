# 0.0.6 发布说明

`0.0.6` 是继 `0.0.5` 之后的正式版本，修复同一命中视频向上跳过后，再向下返回时偶发漏跳的问题。

状态：本次目标代码、回归和发布文档已提交并推送至 `origin/master`，正式安装产物版本为 `0.0.6`。

## 变化

- React 当前树轮换时，沿已知祖先路径验证导航入口的每层兄弟节点预算由 128 调整为 512，避免有效入口被提前拒绝。累计 2048 节点、深度、循环、当前树、宿主、身份、Feed 归属和派发前校验保留；超限或不确定时继续放行。
- 原生入口发现失败时记录有界匿名化摘要，便于区分控件缺失和入口校验失败，不输出关键词、视频身份、账号信息或页面原数据。
- 提供从权威发现函数生成的显式 Console 检查工具，可保留现有页面现场。观察模式最多两分钟或 100 条变化摘要，只收集影响活动卡的变化并合并采样，卡片查询限定在已验证 Feed 内，全页根唯一性每秒复核，结束、后台、Feed 失效和异常时清理。

## 验证与限制

主脚本、原生探针、生成器及生成代码语法检查、265/265 Node 回归和差异检查通过。默认 `node --test` 受环境 `spawn EPERM` 限制，全量回归使用 `node --test --test-isolation=none`。

新增控制器回归覆盖同一卡片先向上跳过、切换到宽兄弟列表的当前树后再向下进入；旧预算下第二次没有派发，修复后两个方向都通过。边界测试保留每层 512、累计 2048、身份及归属拒绝。两个独立审查者发现的诊断观察器重复扫描问题已经修复，原审查者离线复核确认解决，未发现明确新增问题。

Chrome + Tampermonkey 定向实页取得同一实际命中卡向上越过、再次向下进入仍自动跳过的单步证据，前后目的卡一致，没有新增导航降级日志；用户确认恢复原关键词配置。当时用户安装的本次修复产物仍标记 `0.0.5`，没有独立核对扩展编辑器源码哈希。正式版整理只修改版本元数据，不能写成 `0.0.6` 安装后的独立实测。详见[排查记录](2026-10-02-reentry-navigation-diagnosis.md)。

原始现场在刷新后丢失，后续验证使用另一张实际命中卡；快速连续输入中未到达预期卡片的样本不计通过。诊断观察器本轮修改只有离线验证，尚未重新运行实页。历史 `queue-timeout` 放行、其他浏览器、语义控件、模态框、后台、实页熔断、精确时序、网络/性能和音频/逐帧验收仍有缺口，不据本次版本变化改写为已通过。

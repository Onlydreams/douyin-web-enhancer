# 0.0.4 发布说明

`0.0.4` 是继 `0.0.3` 之后的正式版本。此前的 `0.0.4-test` 至 `0.0.12-test` 是开发候选，不占用正式发布编号。本版运行逻辑与已实测的 `0.0.12-test` 相同；本次发布准备只改 Userscript 版本元数据和说明文档。

## 变化

- 推荐流的下一条控件缺失时，经过当前视频身份、Feed 归属和导航实例校验后，使用页面原生导航入口。支持按照实际进入方向向上或向下越过命中卡；连续命中沿用该方向。
- 首次目标项尚未进入页面队列时，每 50ms 检查、最多等待 2500ms；动画未结束时也有独立的 2500ms 上限。就绪后立即继续，超时或身份不确定时放行。
- 进入可见直播卡时清理旧视频导航状态；直播本身不参与关键词过滤。
- 增加 `@updateURL` 和 `@downloadURL`，指向正式脚本在仓库 `master` 分支的文件。在线更新链路尚未实测。

## 验证与限制

Chrome + Tampermonkey 中，连续两张命中卡的两组向下／向上往返方向正确，未记录产品降级日志。后续三轮限定采样中，两次首次队列从长度 2 补齐后自动派发，另有多张连续跳过；用户近期日常使用未再遇到故障。这些结果不能证明历史队列超时已消除。队列超过等待上限时仍放行，页面可继续正常播放。

BGM、弹幕和 Edge 的既有证据见 [Stage 5 验收报告](./2026-08-13-stage-5-evidence.md)，不能当作 `0.0.4` 的逐项重新实测。浏览器音频、逐帧目标、其他浏览器和在线自动更新仍未完成本版验收。

此前手动安装 `0.0.12-test` 的用户，需要从正式脚本地址手动重新安装或替换为 `0.0.4`；不能依赖自动更新从较高的测试版号降到 `0.0.4`。

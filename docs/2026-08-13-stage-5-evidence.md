## 发布前独立审查处置

| 审核意见 | 处置 | 结果 |
| --- | --- | --- |
| BGM fetch/XHR 的旧异步回调可跨越 `stop() -> start()` | 采纳 | `0.4.9` 为每次观察运行增加唯一令牌；旧 fetch 解析和已排队 XHR 微任务不能向新运行投递，并新增两条回归 |
| 全局 MutationObserver 与 750ms 健康检查会触发整页扫描 | 采纳 | 全局回调只检查变更节点；弹幕依赖增量 Observer；内联 BGM 脚本只在启动、配置更新和新增 script 时解析；健康检查只核对路由与 Feed 根身份 |
| BGM 卡片关联未显式验证后代 `aweme_id/gid` | 采纳 | 新增卡片身份 Adapter；卡片 `data-e2e-vid` 必须与唯一后代 `aweme_id/gid` 一致，缺失、格式错误或冲突均 fail-open |
| 动画容器依赖裸 `parentElement.parentElement` | 采纳 | 收敛为内部页面 Adapter，页面层级变化时统一降级到当前 Feed 根 |
| 首版网络 DTO 缺少视频 `itemTitle/desc/caption` | 不作为实现缺失采纳 | 当前产品契约是视频文本只读 `[data-e2e="video-desc"]` 与话题；网络观察器只服务 BGM。设计文档已同步这一边界，避免在没有作者隔离和迟到字段实页证据时扩大数据面 |
| 未闭环 Network、性能和长时生命周期验收却声明 Stage 5 完成 | 采纳 | 状态降为发布候选；`0.4.10` 定向崩溃回归已通过，Network 无新增请求、独立性能采样和 15 分钟生命周期验收仍是正式发布前缺口 |

`0.4.9` 最小实页回归确认视频关键词、独立 BGM 命中、双向自动越过以及弹幕命中隐藏均生效；关闭弹幕规则后页面根和弹幕节点所有权已清理，未发现脚本控制台错误。随后连续导航与评论区加载后的抖音渲染进程增长到约 1GB 并失去响应，Tampermonkey 菜单 prompt 也无法出现。离线压力回归确认普通评论 `childList` 变更会触发弹幕、Feed 和 script 的多次后代选择器查询。

`0.4.10` 改为最多访问 64 个新增元素的有界遍历，并通过“无关评论节点零后代查询”回归。更新后的 Chrome + Tampermonkey 页面完成 12 次向下、6 次向上以及后续 60 次持续方向切换，共 78 次导航输入；过程中无页面操作超时，随后空闲 15 秒仍可读取 3 个 Feed 卡片。最大 Chrome 进程工作集采样从约 712 MB 增至 835 MB，没有复现此前约 1 GB 后失去响应的状态。回归结束后用户确认 BGM 编辑菜单 prompt 正常弹出。该证据支持定向崩溃回归通过，但短时进程采样不替代独立性能或 15 分钟生命周期验收。

## 隐私与公开检查

- Userscript 只声明 GM 本地存储和菜单权限，无 `GM_xmlhttpRequest`、`@connect`、Cookie、下载、剪贴板或通知权限；
- 产品脚本不发送额外请求，不点击会改变账号状态的控件；
- 关键词不写入页面 DOM、网络或日志；
- 仓库扫描未发现本机用户路径、认证头、真实 Token、Cookie、密码或账号标识；
- 测试中的 `token=secret` 是验证脱敏器的合成输入，不是真实凭据；
- fixture 和报告只保留匿名结构与完成验收所需的最小证据。

## 已知限制与未验证项

- 视频/BGM 自动跳过只支持抖音首页“推荐”标准视频流；
- 弹幕过滤只覆盖存在可识别 `[data-danmu-id]` 节点的视频页面；
- 不承诺直播、图文、短剧、放映厅、搜索、个人主页、评论区、广告或游戏推广卡片；
- 最终版本未在 Edge、Firefox、Violentmonkey 或 Safari 复测；
- Network 面板无新增请求、独立性能采样、系统音频采样和高帧率零帧仍未取得独立人工证据；
- 当前不写 `muted`，不调用 `pause()/play()`，不承诺绝对零音频或零帧。

这些缺口不冒充已通过。当前产物只能标为发布候选；正式发布状态需至少补齐 Network 无新增请求、独立性能采样和 15 分钟生命周期验收，或由发布负责人明确缩减验收契约后重新记录。

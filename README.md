# 抖音 Web 增强

一个单文件、零构建、零第三方运行时依赖的抖音 Web 端 Tampermonkey Userscript。

- Stage 0 真实页面证据采集与收敛：活动卡片、三卡虚拟窗口、视频文本边界、弹幕结构、Tampermonkey 注入、XHR Feed 和 BGM 字段关联；

## 安装与更新

1. 安装 Chrome 和 Tampermonkey；当前实页证据来自 Chrome + Tampermonkey，其他浏览器尚未完成兼容性验收。
2. 在 Tampermonkey 中新建脚本。
3. 用根目录 [`douyin-web-enhancer.user.js`](./douyin-web-enhancer.user.js) 的完整内容替换编辑器内容并保存。
4. 打开或刷新 `https://www.douyin.com/?recommend=1`。

更新时重复第 3 步并保存，然后刷新抖音页面。不要安装 `tools/` 下的诊断探针作为日常产品脚本。

## 配置与使用

打开 Tampermonkey 扩展菜单，在“抖音 Web 增强”下分别配置：

- “编辑视频屏蔽词”：用于推荐流标题、描述和话题；
- “编辑 BGM 屏蔽词”：同时匹配原声音轨名和平台明确关联歌曲名；
- “编辑弹幕屏蔽词”：用于单个视频内的弹幕显示文本。

多个关键词使用竖线 `|` 分隔。状态菜单可单独开启或关闭每类规则；关闭后保留已保存关键词，清空编辑框则删除该类关键词。视频/BGM 配置变更不突袭当前已稳定播放的视频，从下一次激活开始生效；弹幕配置对当前页面立即重判。

## 功能

### 视频关键词屏蔽

根据推荐视频的标题、描述和话题匹配本地关键词。命中后保持视觉门控，并通过已在 Chrome + Tampermonkey 3/3 验证的语义化下一条控件进入后续内容；活动视频 ID 未变化时最多重试一次，随后放行并提示。15 秒内连续确认跳过 12 条会触发熔断。

### 弹幕关键词屏蔽

在任意视频页面的弹幕首次绘制前匹配显示文本，只隐藏命中的弹幕，不删除节点，也不改变抖音原生弹幕开关；该功能不依赖推荐流或自动下一条能力。

### BGM 名称屏蔽

读取页面本来就会接收的视频元数据，同时匹配原声条目的 `music.title/musicName` 和平台明确关联歌曲的 `relatedMusicAnchor.extra.title`。首版只允许通过 `awemeId/gid` 精确关联视频；无法可靠关联时放行。

## 设计原则

- 单文件 Userscript，同时作为源代码和安装产物；
- 零构建、零第三方运行时依赖；
- 关键词仅保存在 GM 本地存储中，不写入页面 DOM，不发送到网络；
- 不调用抖音私有接口，不发送额外网络请求；
- 不点击“不感兴趣”，不修改账号推荐画像；
- 页面或数据结构不确定时 fail-open，优先保持抖音原生功能可用；
- 站点易变的 DOM 和数据细节集中在内部适配函数中；
- 源码测试、代理真实浏览器验证和用户手工验收分别记录，不互相替代。

## 首版范围

视频关键词与 BGM 关键词的自动跳过当前只支持：

- `https://www.douyin.com/` 首页推荐流；
- `https://www.douyin.com/?recommend=1` 推荐流；
- 标准视频卡片。

弹幕关键词是独立的单视频内显示过滤，只要页面使用可识别的 `[data-danmu-id]` 弹幕节点即可工作，不受上述推荐流范围限制。

首版不承诺支持直播、图文、短剧、放映厅、搜索结果、个人主页、评论区、广告或游戏推广卡片，也不承诺兼容 Firefox、Violentmonkey 和 Safari。

## 无感过滤边界

“无感”的方向是：尽量让命中视频不产生可听音频、不进入稳定画面，让命中弹幕不先显示再消失，并避免连续命中的预加载视频逐条闪现。

Stage 0 已确认页面注入、XHR Feed、BGM 字段关联和媒体/弹幕结构；同时观察到首个视频帧早于现有标准活动卡片信号，因此首版不承诺数学意义的绝对零帧或零音频。250ms 视频/BGM 门控和 100ms 弹幕门控只是可见前台标签页中的测量目标，不是后台标签页或所有浏览器状态下的绝对保证。

可靠的可编程导航已经通过 Stage 2 实页能力闸门；`0.4.8` 的双向导航和连续命中已通过用户手工验收。临时静音争用与恢复、高帧率录屏和系统音频采样仍待验证；当前候选版不写 `muted`，也不调用 `pause()/play()`。任一剩余能力未通过时，项目会禁用对应动作或降低承诺。

## 隐私、权限与停用

- 只申请 `GM_getValue`、`GM_setValue`、`GM_registerMenuCommand` 和 `GM_unregisterMenuCommand`；
- 关键词仅保存在 Tampermonkey 的 GM 本地存储中，不写入页面 DOM，不发送到网络；
- 不读取 Cookie、Local Storage、浏览历史或额外账号数据；
- 不点击“不感兴趣”、关注、点赞、评论等会改变账号状态的控件；
- BGM 只观察页面本来会接收的数据，不调用私有接口，不发送额外请求；
- 停用时可在 Tampermonkey 管理面板关闭脚本并刷新抖音；卸载时直接删除该脚本。脚本停止、关闭规则或离开支持页面时只恢复自己拥有的页面状态。

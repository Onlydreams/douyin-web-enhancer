# 抖音 Web 增强

一个单文件、零构建、零第三方运行时依赖的抖音 Web 端 Tampermonkey Userscript。

## 功能

当前正式版本为 `0.0.6`，上一正式发布版本为 `0.0.5`。测试候选编号不计入正式发布序列。首次加载时若下一条尚未进入页面队列，脚本最多等待 2500ms，超时后放行；历史偶发超时不能视为已彻底消除。

`0.0.6` 修复同一命中视频向上跳过后，再向下返回时偶发漏跳的问题。React 当前树轮换时，旧兄弟节点预算可能错误拒绝有效导航入口；本版扩大每层预算并保留累计上限、身份、归属和派发前校验，失败仍放行。新增匿名化诊断摘要及可保留现场的 Console 检查工具。265 项 Node 回归通过；Chrome 定向实页证据来自仍标记 `0.0.5` 的本次修复代码，正式版整理仅修改版本元数据。详见[0.0.6 发布说明](docs/2026-10-02-release-0.0.6.md)和[重复进入排查记录](docs/2026-10-02-reentry-navigation-diagnosis.md)。

上一正式版 `0.0.5` 的导航修复：控件可用时也记录可信输入方向；等待、沉降和重试都检查推荐路由、唯一 Feed 根、活动身份与交互状态；人工接管会取消旧等待并保留新方向。只有确认到达派发目标才继承方向并计入熔断，原生目标取自已验证队列；目标不符或不明确时停止连续跳过，动画/队列等待过期后不再派发。视频/BGM 原始配置文本变化可解除熔断。当时 254 项 Node 回归通过，Chrome + Tampermonkey 取得连续两张命中的双向过滤、直播止步、当前卡配置保护、人工接管和一次 SPA 清理/恢复证据。队首及重复往返仍观察到 `queue-timeout` 放行；语义控件、模态框、后台和实页熔断尚未验收，完整记录见[发布前实页验收](docs/2026-09-30-real-page-acceptance.md)，版本变化见[0.0.5 发布说明](docs/2026-09-30-release-0.0.5.md)。

### 视频关键词过滤

脚本根据推荐视频卡片中可识别的标题、描述和话题匹配本地关键词，不匹配作者、互动数字、章节摘要、AI 摘要或页面其他文字。

命中后，脚本优先通过页面的上一条或下一条控件越过该视频。控件不可用时，尝试经过当前 React 树、视频身份和 Feed 归属校验的页面原生导航入口。无法可靠识别当前视频、导航实例或切换结果时会放行；15 秒内确认跳过 12 条会触发熔断并暂停自动跳过，避免过宽关键词造成连续跳过。

### BGM 名称过滤

脚本匹配原声 `music.title/musicName`，以及同一视频对象内平台明确关联歌曲的 `relatedMusicAnchor.extra.title`。

BGM 只通过 `awemeId/gid` 与视频卡片精确关联。脚本有界解析运行期间新增的 QuickPlayer 数据，并只读观察页面本来就会接收的同源 Feed 响应；不扫描历史 script，不调用私有接口，也不发送额外请求。无 ID、ID 冲突、解析失败或已有一个响应正文正在处理时均放行。

### 弹幕关键词过滤

脚本处理可识别的 `[data-danmu-id]` 弹幕节点，包括首批节点、动态新增、文本后填充和节点复用。命中时只隐藏对应弹幕，不删除节点，也不改变抖音原生弹幕开关。

弹幕过滤独立于推荐流和自动跳过能力，可在使用相同弹幕节点结构的其他视频页面工作。关闭规则、停止脚本或页面结构变化时，只恢复脚本自己标记的节点。

## 配置

打开 Tampermonkey 扩展菜单，在“抖音 Web 增强”下分别配置：

- “编辑视频屏蔽词”：匹配推荐流视频标题、描述和话题；
- “编辑 BGM 屏蔽词”：匹配原声音轨名和平台明确关联的歌曲名；
- “编辑弹幕屏蔽词”：匹配弹幕显示文本。

多个关键词使用竖线 `|` 分隔。关键词会经过 NFKC 规范化、去空和去重，菜单只显示有效词数，不显示关键词内容。

每类规则都可以单独开启或关闭。关闭规则会保留已保存的关键词；清空编辑框会删除该类关键词。视频和 BGM 配置从下一次视频激活开始生效，不会突袭跳过当前已稳定播放的视频；弹幕配置会立即重判当前页面中的弹幕。

标签页重新获得焦点时会读取 GM 本地配置；跨标签页配置同步的实页回归尚未完成。建议在当前抖音标签页编辑规则。

## 安装与更新

1. 安装 Chrome 和 Tampermonkey（当前主要验证环境）。
2. 在 Tampermonkey 中新建脚本。
3. 用 [`douyin-web-enhancer.user.js`](./douyin-web-enhancer.user.js) 的完整内容替换编辑器内容并保存。
4. 打开或刷新 `https://www.douyin.com/?recommend=1`。

更新时重新执行第 3 步并刷新抖音页面。产品不手工配置更新和下载元数据；请使用上述手动替换流程。已经安装 `0.0.12-test` 或此前版本的用户需要手动替换为 `0.0.6`。不要把 `tools/` 下的诊断探针作为日常产品脚本安装。

以下 Chrome 长时与 SPA 记录来自 `1.0.10-test`，此前 `0.0.2` 沿用其实现与证据；Edge 为历史定向检查。这些记录不代表 `0.0.6` 已在这些环境中重新验收：

| 环境 | 视频/BGM 自动跳过 | 弹幕关键词过滤 |
| --- | --- | --- |
| Chrome + Tampermonkey | 已在首页推荐流完成三类过滤功能回归，以及约 15.6 分钟推荐流和 3 次 SPA 往返定向验证 | 已在推荐页和独立视频页验证 |
| Edge + Tampermonkey | 当前推荐流未暴露脚本依赖的语义化上一条/下一条控件；命中后无法可靠自动跳过，脚本会提示并放行当前视频 | 不依赖视频切换控件，但 Edge 实页功能验收尚未完成 |

Edge 中真实鼠标滚轮或键盘向下可以切换视频，但 Userscript 派发的合成 `WheelEvent` / `KeyboardEvent` 不能可靠触发同样行为，因此不作为自动跳过的替代方案。其他浏览器和 Userscript 管理器尚未完成兼容性验收。

## 支持范围与已知限制

视频和 BGM 自动跳过当前只支持：

- `https://www.douyin.com/` 首页推荐流；
- `https://www.douyin.com/?recommend=1` 推荐流；
- 可识别的标准视频卡片。

当前不承诺支持直播、图文、短剧、放映厅、搜索结果、个人主页、评论区、广告或游戏推广卡片。

页面或数据结构不确定时，脚本会 fail-open，优先保持抖音原生功能可用。前台 250ms 视频/BGM 判定和 100ms 弹幕判定是实现目标，不是所有页面状态下的绝对保证。当前版本不写 `muted`，也不调用 `pause()/play()`，因此不承诺绝对零音频或零帧。

Network 面板、独立性能 trace、后台标签页、系统音频和高帧率零帧验收尚未完成。详细的设计、历史诊断过程和分层验收证据见 [`docs/`](./docs/)。

## 隐私、权限与停用

- 只申请 `GM_getValue`、`GM_setValue`、`GM_registerMenuCommand` 和 `GM_unregisterMenuCommand`；
- 关键词只保存在 Tampermonkey 的 GM 本地存储中，不写入页面 DOM、不发送到网络，也不输出到日志；
- 编辑关键词使用页面 `window.prompt`；在 raw sandbox 下不能将其视为与页面脚本隔离的秘密输入通道；
- 不读取 Cookie、Local Storage、浏览历史或额外账号数据；
- 不点击“不感兴趣”、关注、点赞、评论等会改变账号状态的控件；
- BGM 观察不修改请求或页面原响应，缓存只保留匹配所需的最小字段；
- 可以在 Tampermonkey 管理面板关闭脚本并刷新页面，或直接卸载脚本。

## 开发

当前原生导航路径不模拟键盘、不包装站点方法、不写媒体属性。每张卡只派发一次原生导航；动画或目标队列项尚未就绪时每 50ms 重新检查，分别最多等待 2500ms，就绪即继续。2.5 秒仍未确认标准视频身份变化则放行，不重发。目的卡为直播等非标准卡时停止本次尝试，不自动跳过直播。输入焦点、模态框、后台、路由或实例不符时放行。用户通过可信按键或滚轮进入相邻卡片时记录进入方向；等待站点切换节流结束后，重新校验并沿进入方向导航。

`0.0.6` 的重复进入修复：实页祖先的兄弟列表超过 128，旧上限会错误拒绝有效入口。每层上限调整为 512，保留累计 2048 节点、深度、循环、身份和归属校验。独立审查修复诊断工具后，265 项 Node 测试通过；用户更新后，Chrome 实页取得同一命中卡向上越过、再次向下进入仍跳过的单步证据，前后落点一致，无新增降级日志，当时安装产物仍标记 `0.0.5`。快速连续输入中未发生切换的样本不计为过滤通过，见[排查记录](docs/2026-10-02-reentry-navigation-diagnosis.md)。原生入口验证失败时只记录有界、无身份信息的诊断摘要。

保留现场时可运行 `node tools/create-reentry-inspection.js` 生成一次性 Console 检查代码，在现有页面手动执行，无需安装或刷新；加 `--watch` 可生成最多两分钟或 100 条变化摘要的只读观察。观察器只收集相关节点变化，由 25ms 采样合并处理，活动卡查询限定于已验证 Feed；全页根唯一性每秒复核，Feed 断开或不再匹配时在下一次采样停止，结束、后台和异常时自动清理。本轮观察工具修改已完成离线验证，尚未重新运行实页。

`0.0.3` 包含以下修复：

- 弹幕仅对已标记的 `pending/block` 节点启用隐藏；单批新增元素超过 64 个时，未遍历到的弹幕默认放行，避免正常弹幕长期不可见。溢出节点可能漏判，后续文本或 ID 变化仍会触发重判。
- BGM 正文处理槽跨同一页面的观察器实例共享，SPA 往返、规则开关或控制器重启都不会绕过尚未结束的读取。
- Feed 变更记录超过处理预算时，仍清理已离开 Feed 的脚本所有权，并阻止旧变更记录重新接管已移除卡片。

这些是 `0.0.3` 的历史修复记录；后续测试候选及分层验收见 [`Stage 5 验收报告`](./docs/2026-08-13-stage-5-evidence.md)。

项目没有构建步骤或第三方依赖。Node.js 18 或更高版本可运行：

```powershell
node --check .\douyin-web-enhancer.user.js
node --test
git diff --check
```

修改诊断探针时，再分别执行对应的 `node --check`。Node 测试不能替代 Tampermonkey 注入时序、真实 DOM、网络、音频或浏览器性能验收。

`douyin-web-enhancer.user.js` 同时是源代码和可安装产物；`tools/` 只保存显式启用的诊断探针。

排查偶发超时时，可临时安装 `tools/native-navigation-probe.user.js` `0.6.1-test`，保持产品脚本启用，并在推荐页 URL 加 `dwe_native_probe=observe-product` 后加载。探针仅在该参数下运行、不会主动切换；最多等待 5 分钟，观察到活动命中卡后记录原生事件、切换方法和队列状态，并在 3.5 秒后恢复包装。结果不输出视频 ID 或关键词，结束后停用探针。

比较同一卡首次和再次进入时，改用 `dwe_native_probe=observe-pair`。普通点击页面对照按钮记录自动跳过；Shift 点击后在 3.5 秒内按方向键，可记录手动导航。每轮结束后探针恢复包装，测量记录不能替代产品脚本的完整实页验收。
